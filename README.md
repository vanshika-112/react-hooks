# Counter App

A simple and interactive Counter Application built using **React.js** and the **useState Hook**.

## 🚀 Features

- Displays the current counter value.
- Increment button (+) to increase the count by 1.
- Decrement button (-) to decrease the count by 1.
- Updates the UI dynamically using React's `useState` hook.
- Simple and clean user interface.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML
- CSS
- React `useState` Hook

## 📖 Concepts Learned

- Understanding React Functional Components.
- Using the `useState` Hook to manage state.
- Handling button click events using `onClick`.
- Updating component state dynamically.
- Understanding React re-rendering.

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd counter
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 💡 How It Works

The application uses React's `useState` hook to store and update the counter value.

- The initial counter value is `0`.
- Clicking the **+** button increases the value by 1.
- Clicking the **-** button decreases the value by 1.
- React automatically updates the UI whenever the state changes.

## 🎯 Project Purpose

To learn React's `useState` hook by creating a simple counter with increment and decrement functionality.
